## Further defects found during remediation

- Browser WebSocket admission exposed missing Vite proxy support, missing uvicorn transport and missing selected subprotocol. Fixed all three; the real browser now connects with a valid ticket and rejects missing/reused tickets.
- A delayed dashboard refresh could restore an already-resolved alert. A focused component regression first failed with New replacing Resolved. Refresh sequencing and revision-aware acknowledgement updates now retain authoritative state; the regression passes.
- The kiosk uploader still showed historical mock confidence without a fixture warning. A focused component regression first failed. Both document views now label mock output, suppress its invented confidence and preserve unknown flags; the regression passes.
- ESLint identified preview state updates in an effect and recording cleanup warnings. The preview URL is bound to its document/session and revoked on cleanup; recorder cancellation is covered by a retained test. Lint passes.
